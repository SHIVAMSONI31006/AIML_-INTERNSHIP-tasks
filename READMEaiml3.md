# Task 3: Linear Regression Implementation

This repository contains the implementation of a **Simple Linear Regression** model using Python and Scikit-learn to predict salaries based on work experience.

## Objective
* Implement and understand simple & multiple linear regression.
* Perform data preprocessing and train-test splitting.
* Evaluate the model using standard metrics (MAE, MSE, $R^2$).
* Visualize the regression line and interpret coefficients.

## Tech Stack & Tools
* **Language:** Python 3
* **Libraries:** Scikit-learn, Pandas, NumPy, Matplotlib
* **IDE:** VS Code
